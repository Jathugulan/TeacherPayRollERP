🔐 2. Google OAuth 2.0 Integration Mechanics

Google Sign-In is powered by @react-oauth/google on the client and google-auth-library on the server:

  1. Frontend Trigger: The user clicks "Continue with Google (Teacher)". The Google Identity Services modal opens.
  2. Credential Reception: On consent, Google returns an ID token (JWT) to credentialResponse.credential.
  3. Token Dispatch: The client executes POST http://localhost:5000/api/auth/google with payload { token }.
  4. Server Validation: OAuth2Client.verifyIdToken() cryptographically validates the token against Google's public keys and the registered GOOGLE_CLIENT_ID.
  5. User Provisioning: If the email exists, the account is logged in with original roles preserved. If new, a user entity is auto-provisioned with role Teacher.
  6. Session Issuance: The backend generates the application's standard JWT and attaches the HTTP-only refresh cookie.

🧮 3. Mathematical Payroll Calculation Engine

The payroll engine executes deterministic, rule-based mathematical calculations to ensure exact salary compliance across all faculty members:

📐 Payroll Formula Specification:
1. Gross Base = Present Days × Daily Rate (Rs. 500)
2. Absence Deduction = Absent Days × Rs. 100
3. Extra Leaves = max(0, Total Approved Leaves - 5)
4. Leave Deduction = Extra Leaves × Rs. 100
5. Total Deductions = Absence Deduction + Leave Deduction + Misc Deductions
6. Net Salary = Gross Base - Total Deductions + Allowances
